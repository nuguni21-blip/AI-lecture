1. 아래 [바이브 코딩 프롬프트]에서 [ ] 안의 세 칸만 우리 회사 것으로 바꿔 넣습니다.
   → [업종/분야] [회사명] [제품·서비스명]

5. 마음에 들면 그대로 쓰고, 고치고 싶은 점을 말로 이어서 부탁합니다.
   예) "입력칸 글자를 더 크게 해 줘", "결과를 인쇄할 수 있게 해 줘"


──────────────────────────────────────────────
■ 바이브 코딩 프롬프트 (여기부터 복사)
──────────────────────────────────────────────

당신은 한국 중소기업의 홍보를 돕는 웹 개발자입니다. 아래 조건대로 '숏폼·홍보 만들기 생성기' 웹앱을 HTML 1개 파일로 만들어 주세요.

[우리 회사 정보 — 이 값을 입력칸의 기본값으로 넣어 주세요]
· 업종/분야: [업종/분야]
· 회사명: [회사명]
· 제품·서비스명: [제품·서비스명]
· 핵심 특징: [핵심 특징 1] / [핵심 특징 2] / [핵심 특징 3]
· 타깃 고객: [타깃 고객]

[화면 구성]
1) 맨 위에 제목과 한 줄 설명을 넣습니다.
2) 입력 칸 7개를 카드 안에 세로로 놓습니다.
   - 업종/분야 (글자 입력)
   - 회사명 (글자 입력)
   - 제품·서비스명 (글자 입력)
   - 핵심 특징 3가지 (글자 입력 3칸, 번호 ①②③ 표시)
   - 타깃 고객 (글자 입력)
   - 영상 목적 (고르기: 제품 홍보 / 기업 소개 / 박람회·영업 / 채용)
   - 톤앤매너 (고르기: 신뢰·전문 / 친근·따뜻함 / 임팩트·역동 / 고급·프리미엄 / 유쾌·유머)
3) 입력 칸 위에 '예시로 채우기' 버튼 3개를 둡니다. (예: 발효식품, 친환경 농자재, 서비스업) 누르면 그 예시 값이 입력칸에 채워지고 결과도 바로 만들어집니다.
4) 큰 [숏폼 세트 만들기] 버튼과 [지우기] 버튼을 둡니다.

[결과물 — 버튼을 누르면 아래 4가지가 한 번에 화면에 나옵니다]
① 30초 숏폼 대본 + 4컷 스토리보드
   - 4컷의 시간은 0–3초 / 3–12초 / 12–22초 / 22–30초로 고정합니다.
   - 컷마다 '화면(무엇이 보이는지) / 자막(15자 이내) / 내레이션(읽을 문장)' 세 줄로 정리합니다.
   - 영상 목적에 따라 4컷의 역할을 바꿉니다. (제품 홍보는 훅→제품 등장→특징 3가지→문의, 기업 소개는 훅→현장과 사람→지키는 3가지→방문 초대, 박람회·영업은 훅→부스에서 보여줄 것→상담 포인트 3가지→부스 위치, 채용은 훅→현장→다른 점 3가지→지원 방법)
   - 톤앤매너에 따라 내레이션 말투와 화면 색감·조명 지시를 바꿉니다.
② 이미지 생성용 프롬프트 4종 (컷마다 1개, 각각 따로 복사)
   - 한 프롬프트 안에 회사 정보·제품·특징·타깃·장면·색감·구도를 모두 적어, 앞 단계 자료를 보지 않아도 그대로 쓸 수 있게 합니다.
   - 세로 9:16, 아래 1/3은 자막 자리로 비우기, 이미지 안 글자·로고·워터마크 금지, 사람 얼굴 클로즈업 금지를 꼭 넣습니다.
③ 클로드 모션 그래픽·vStory용 프롬프트 1개
   - 클로드에 붙여넣으면 (1) 4장면 표, (2) 30초짜리 세로 HTML 애니메이션 코드 1개, (3) vStory에 넣을 장면별 대본(화면 설명·자막·내레이션·길이)을 한 번에 받도록 지시문을 만듭니다.
   - '앞 단계 자료를 참조하지 말고 이 안의 정보만 쓰라'는 문장을 반드시 넣습니다.
④ SNS 업로드 세트
   - 제목 5개(30자 이내), 인스타그램 릴스 본문, 유튜브 쇼츠 설명, 블로그·카페용 짧은 글, 해시태그 10개를 만듭니다.
   - 본문 첫 문장은 후킹, 마지막은 행동 유도(문의·방문·지원)로 끝냅니다.

[동작 방식]
- 인터넷 연결이나 외부 API 없이, 입력한 값으로 문장을 조립하는 자바스크립트로 동작하게 만드세요.
- 한국어 조사(은/는, 이/가, 을/를, 으로/로)를 받침에 맞게 자동 처리해서 어색한 문장이 나오지 않게 하세요.
- 각 결과 카드마다 [복사] 버튼을, 카드 제목 옆에는 [전체 복사] 버튼을 둡니다. 복사가 안 되는 환경을 대비해 예비 방법(글자 선택)도 넣으세요.
- 복사하면 '복사했습니다' 안내가 2초 정도 떴다가 사라지게 하세요.
- 비워 둔 칸은 [회사명]처럼 대괄호 자리표시자로 결과에 나오게 하세요.

[디자인]
- 한국어 화면, 흰 바탕에 진한 초록 계열 포인트, 카드 모서리 둥글게.
- 40~60대도 읽기 쉽게 본문 16px 이상, 결과 글자 15px 이상, 줄 간격 넉넉하게.
- PC 1280px에서는 입력 칸이 왼쪽·결과가 오른쪽 2단, 모바일 390px에서는 위아래 1단으로 자연스럽게 바뀌게 하세요. 가로 스크롤이 생기면 안 됩니다.
- 표 대신 카드와 목록을 써서 폰에서도 글자가 잘리지 않게 하세요.

[지켜야 할 것]
1. 제가 주지 않은 수치·인증·수상 경력·효능은 만들지 말고, 필요한 자리는 '확인 필요'로 표시하세요.
2. 식품·건강기능식품의 질병 예방·치료 효능 표현은 절대 쓰지 마세요.
3. 외부 라이브러리·외부 이미지·외부 폰트를 쓰지 말고 HTML 1개 파일로 완성하세요.
4. 완성하면 Canvas에서 바로 미리보기로 보여 주고, 사용법 3줄을 아래에 적어 주세요.

■ 폰 홈 화면에 추가하는 4단계
──────────────────────────────────────────────
① PC나 폰의 제미나이에서 위 프롬프트로 캔버스(Canvas) 앱을 만든 뒤, 폰 제미나이 앱에서 그 대화를 엽니다.
② 오른쪽 위 공유 버튼을 눌러 링크를 복사합니다.
③ 폰 크롬(Chrome) 주소창에 그 링크를 붙여넣어 엽니다.
④ 오른쪽 위 점 세 개(⋮)를 누르고 [홈 화면에 추가] → [추가]를 누릅니다.

· 안드로이드는 크롬, 아이폰은 사파리에서 [공유] → [홈 화면에 추가]를 쓰면 됩니다.
· 앱처럼 아이콘이 생기고, 다음부터는 누르면 바로 열립니다.
· 캔버스 공유 링크가 열리지 않으면, 캔버스의 [코드 복사]로 HTML을 받아 구글 드라이브에 올린 뒤 드라이브에서 열어 같은 방법으로 추가하면 됩니다. 막히면 강사에게 알려 주세요.
